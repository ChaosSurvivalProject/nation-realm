# 经济

## 复式记账
- 每笔交易至少两条分录，借方总额 = 贷方总额；`Ledger.validateConservation()` 保证全账本总额恒为 0。
- 不直接改余额；国库、成员钱包、国家基金、建筑维护、NPC 工资、食物、军队、研究、征税、外交成本都生成交易与审计。

## 金额
- 定点整数最小货币单位（`Money`），禁止 `double`/`float`。

## 幂等与并发
- 每笔交易带幂等键；重复请求返回原交易 ID，不重复扣款。
- 取消 / 退款有完整反向分录。
- 并行建造通过预算校验 + 乐观锁，不超支。

## GDP
- GDP 是周期生产价值指标（`GdpCalculator`），只读汇总，**不能当余额扣减**。
- NPC 招募、维护、供给影响劳动力与支出，计入成本而非直接冲减 GDP。

## 审计
重要操作记录：操作者、旧值、新值、原因、时间、关联交易。
