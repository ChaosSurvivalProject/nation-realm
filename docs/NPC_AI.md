# NPC 与 AI

## 身份透明（硬性）
- AI 默认厂商标识 **DeepSeek**；默认模型配置键 `deepseek-flash-4.1`（存在性与接口可达性未经核实，仅作配置）。
- 模型调用通过用户授权的 Base URL / API Key / 可用模型列表校验；启动只警告，不阻断离线玩法。
- NPC 永久带 AI 标记（Tab 前缀、聊天标签、资料页、`ai_visible` 字段）。禁止不可见字符、同形字符冒名、绕过重名检查、隐藏 AI 身份。
- 随机姓名用可显示合法字符 + 国家文化词库 + 唯一编号；重名追加可见编号；结果可审计。

## 上限与生存
- 每国最多 80 AI NPC，服务端原子约束（配置不可超过 80）。
- NPC 会饥饿、受伤、疲劳、消耗工具物资；不能无限劳力/运输/战斗。
- 一键补给带二次确认与成本预览，消耗国家物资与资金，受仓库/距离/物流限制。

## AI 安全
- 模型只返回受约束意图 JSON（`Intent`）；白名单 action + forbidden 字段检测 + JSON校验（`IntentValidator`）。
- Prompt 不能执行游戏操作；模型不可接触控制台、DB 凭据、OP、玩家令牌、任意网络地址或命令。
- 服务端状态机验证距离/权限/成本/冷却/危险/安全后才执行（`NpcStateMachine.allowAiSuggestion`）。
- 预算：每国/每服务器每分钟限额、队列上限、超时、重试、熔断（`CircuitBreaker`）、缓存、每日成本上限（`BudgetGuard`）。
- 异步工作器；记忆只存必要摘要，敏感信息/完整聊天/密钥不送模型。

## 离线降级
AI 关闭时 NPC 按确定性行为树继续工作/吃饭/休息/防守/返回，不集体静止（`NpcStateMachine.decide`）。

## 密钥
API Key 只在 AI 工作器环境变量 `NATION_AI_KEY`；绝不写仓库/配置示例/DB/客户端/日志。
