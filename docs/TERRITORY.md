# 领土与地图

## 区块记录
- 区块级静态记录，不加载区块、不常加载、不生成地形。
- 记录探索者、时间、国家、所有权、数据源、版本。
- 未探索区块显示“未知”，不可凭空推断。
- 存储用区域位图（32×32 区块/区域）+ 稀疏数组，禁止每区块一个对象（`ChunkBitmap`）。

## 探索
玩家移动按区块坐标批量入队、去重、异步落库；不加载区块。落库失败退避重试，不循环刷日志。

## 地图着色
- 优先三色邻接着色；数学上不保证三色可解，冲突时加第四色。
- 必须叠加边界、虚线、纹理、国家缩写或选中高亮——色盲玩家不能只靠颜色分辨。
- 2D/3D 切换、缩放、平移、旋转、区块/区域两级细节。
- 3D 是客户端基于真实数据生成的全息式可视化，不常驻整个世界；地形随缩放分层获取。

## 性能
- 分层瓦片 + 可见区域请求；动画用插值，数据只在快照/差分到达时更新。
- 去除不可见区域，限制 GPU 缓冲与纹理缓存，关闭 GUI 释放资源。
